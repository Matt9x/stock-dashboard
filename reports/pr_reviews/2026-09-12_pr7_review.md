## 2. 独立复核与缺陷修复 (Independent Review & Bug Fixes)

在独立隔离沙箱环境（Worktree）中对 PR #7 进行逐项独立核查，发现了 **2 处代码与测试兼容性细节问题**，并均已在合入前完成修复与验证：

### 🔍 问题 1：Pandas 3.0+ StringDtype 赋值引发 TypeError
- **位置**：`tests/test_nale_alpha_panel.py:52`
- **成因**：在 Pandas 3.0+ 默认推断 PyArrow 字符串类型下，测试代码执行 `bad_code.loc[0, "code"] = 1`，由于类型系统强制检查，在进入 `validate_nale_panel` 的正则表达式校验前便抛出了 `TypeError: Invalid value '1' for dtype 'str'`。
- **修复措施**：修改为赋值非六位代码的字符串 `bad_code.loc[0, "code"] = "00001"`，使类型符合 Arrow 字符串规范，同时精确触发并验证了 `validate_nale_panel` 中 `six-digit` 校验异常。

### 🔍 问题 2：正则捕获组产生的 Pandas UserWarning
- **位置**：`src/data/nale_alpha_source_contract.py:75`
- **成因**：使用 `Series.str.contains(r"(Z|[+-]\d{2}:\d{2})$")` 时，括号被识别为捕获组，Pandas 抛出 `UserWarning: This pattern is interpreted as a regular expression, and has match groups.`。
- **修复措施**：将捕获组改为非捕获组 `(?:Z|[+-]\d{2}:\d{2})$`，消除控制台警告，保障质量门禁清洁度。

## 3. 数学公式与边界独立推导 (Mathematical Audit)

根据数学建模审计规则，核验核心公式如下：

1. **B0 矩估计与非负斜率**：
   $$\hat{c} = \begin{cases} \frac{\mathrm{Cov}(x, y)}{\mathrm{Var}(x)}, & \text{若 } \mathrm{Cov}(x,y) > 0 \text{ 且 } \mathrm{Var}(x) > 10^{-15} \\ 0.0, & \text{其他} \end{cases}$$
   $$\hat{a} = \bar{y} - \hat{c} \bar{x}$$
   - 取两点测试 $x=[0, 1], y=[0, 1] \implies \bar{x}=0.5, \bar{y}=0.5 \implies \hat{c}=1.0, \hat{a}=0.0$；
   - 取反相关 $x=[0, 1], y=[1, 0] \implies \mathrm{Cov}=-0.25 \implies \hat{c}=0.0, \hat{a}=0.5$。独立手算与代码行为完全相符。

2. **非线性门控解析梯度**：
   $$L(\theta) = \sum_{i} w_i r_i^2 + \lambda \|\theta\|_2^2$$
   其中 $r_i = a + c(s_{0,i} + \alpha_i \Delta_i) - y_i$，$\alpha_i = 0.05 + 0.70 \sigma(u_i)$，$u_i = w_0 + z_i^T w$。
   复合求导：
   $$\frac{\partial L}{\partial u_i} = 2 w_i r_i \cdot c \Delta_i \cdot 0.70 \sigma(u_i)(1 - \sigma(u_i)) = \mathrm{shared}_i$$
   $$\frac{\partial L}{\partial w_0} = \sum_i \mathrm{shared}_i + 2\lambda w_0$$
   $$\nabla_w L = Z^T \mathrm{shared} + 2\lambda w$$
   解析推导与 `gate_loss_and_gradient` 实现一致，有限差分梯度误差 $< 10^{-7}$。
